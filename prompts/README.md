# Game prompts

One file per game: `prompts/<manifest-id> prompt.md`. Each is a **ready-to-hand build
prompt** - paste the whole file into a session to start work on that game. They are
generated by `Tools/_gen_game_prompts.py` from the knowledge in `FuturePlans/GAME_IDEAS.md` (§1 status
board, §6 entries, §12 prompt contract); regenerate with:

    python Tools/_gen_game_prompts.py

`FuturePlans/GAME_IDEAS.md` remains the single source of truth for status, players and decisions.
These files only restate it as a request, so a session never has to guess the constraints.
They are overwritten on every run - edit the script, never the generated files.
