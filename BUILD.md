# Build Pipeline

The primary command to build the application is `BUILD.bat`.

## Build Process
Run the following command in the project root:
```cmd
BUILD.bat
```
This will:
1. Set the JDK 17 environment.
2. Run `gradle assembleDebug` using the local Gradle distribution.
3. Copy the resulting APK to `shell-debug.apk` in the project root.

## Audio Assets

**The `.ogg` audio files are deliberately NOT in git** (`.gitignore` excludes
`app/src/main/res/raw/*.ogg`). They are generated, and the Kotlin code references them as
`R.raw.*`, so **a fresh clone will not compile until they are regenerated.** Run both scripts
once after cloning, before the first `BUILD.bat`:

```cmd
python _gen_audio.py
python _gen_bgm.py
```

| File | Generated by | Notes |
|---|---|---|
| `bgm_shell.ogg` | `_gen_bgm.py` | seamless-by-construction loop; **must** be generated by this script, not hand-made |
| `sfx_tap.ogg` / `sfx_select.ogg` / `sfx_back.ogg` / `sfx_tick.ogg` | `_gen_audio.py` | UI feedback set |
| `notif_chime.ogg` | *(no committed generator yet)* | notification chime — currently only exists locally |

- Requires **ffmpeg with `libvorbis`** on PATH (`_gen_bgm.py` also probes `C:\ffmpeg\...`).
- Verify any BGM take is seamless with: `python _check_loop.py`
- `_gen_bgm.py` overwrites the `bgm_shell.ogg` that `_gen_audio.py` writes, so run the BGM script
  **after** the audio one.

